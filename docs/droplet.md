# Deploy SMErgers on a DigitalOcean Droplet

This runs Flask and the WhatsApp Web connector together in Docker. Gunicorn uses
one worker because jobs are currently held in memory. The bridge stays on
loopback inside the container. A named volume saves its WhatsApp login session.
Jobs, approvals and imported chats still reset when the app process restarts.

## 1. Create the server

Choose Ubuntu 24.04 LTS, x86-64, Basic, Singapore (or your nearest region), and
an SSH key. Start with 2 vCPUs and 4 GB RAM for a Chromium-based demo; this is a
starting recommendation, not a measured minimum. Record the public IPv4 address.
Allow SSH port 22 from your IP in the DigitalOcean Cloud Firewall. Later allow
TCP 80 and 443 publicly. Do not expose ports 3001 or 5000.

## 2. Connect and install prerequisites

From your computer, replacing DROPLET_IP:

```bash
ssh root@DROPLET_IP
```

On the Droplet:

```bash
apt-get update
apt-get install -y docker.io docker-compose-v2 git nginx apache2-utils certbot python3-certbot-nginx
systemctl enable --now docker
docker compose version
```

## 3. Download and configure the project

First push the Docker files and startup script changes to your deployment branch.
Then, on the Droplet:

```bash
git clone https://github.com/Anonys-sky/SMErgers.git /opt/smergers
cd /opt/smergers
cp .env.example .env
chmod 600 .env
nano .env
```

Replace `SECRET_KEY=change-me` with a random secret generated by
`openssl rand -hex 32`. For AI imports, uncomment and fill `RUNPOD_API_KEY` and
`RUNPOD_ENDPOINT_ID`; optionally set `SMERGERS_LLM_TIMEOUT=240`.
Never commit `.env` or share its secrets.

## 4. Build and test

```bash
docker compose up -d --build
docker compose ps
docker compose exec app npm run check:browser
docker compose logs --tail=100 app
curl -I http://127.0.0.1:5000/
```

For a private first test, open a second terminal on your own computer:

```bash
ssh -L 5050:127.0.0.1:5000 root@DROPLET_IP
```

Keep it connected and open http://localhost:5050. Open the WhatsApp bridge page
and pair a test account through Linked Devices. Use synthetic test chats.
The volume preserves the login across normal container replacements. Deleting
the volume, unlinking the device or an expired session can require pairing again.

## 5. Publish with HTTPS

Point a domain's A record to the Droplet IP. Replace `demo.example.com` below
with that domain. Avoid an AAAA record unless IPv6 is also configured. Allow
ports 80 and 443 in the Cloud Firewall and any enabled host firewall.

The prototype lets visitors switch roles and pair WhatsApp, so password protect
the demonstration before publishing:

```bash
htpasswd -c /etc/nginx/smergers.htpasswd demo
nano /etc/nginx/sites-available/smergers
```

Paste this configuration with your domain:

```nginx
server {
    listen 80;
    server_name demo.example.com;
    client_max_body_size 1m;
    auth_basic "SMErgers demo";
    auth_basic_user_file /etc/nginx/smergers.htpasswd;

    location / {
        proxy_pass http://127.0.0.1:5000;
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 300s;
    }
}
```

Enable the site (create the symlink once):

```bash
ln -s /etc/nginx/sites-available/smergers /etc/nginx/sites-enabled/smergers
nginx -t
systemctl reload nginx
certbot --nginx -d demo.example.com
```

Complete Certbot's prompts, then open your HTTPS URL and enter the demo
credentials. Check import, approvals, client confirmation and CSV downloads.
Give judges both the URL and demo credentials. Basic authentication also blocks
public webhook callers; official Meta webhooks need a separate route design.

## Updates

```bash
cd /opt/smergers
git pull --ff-only
docker compose up -d --build
docker compose logs --tail=100 -f app
```

Restart with `docker compose restart app`; this resets in-memory progress.
Do not run `docker compose down -v` unless you intend to erase the login session.
Keep one app container and one Gunicorn worker until shared database storage
is implemented.
