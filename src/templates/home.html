Export the group without media, select the matching quote, and identify changes for review.

  1. In WhatsApp, open the event group and choose Export chat.
  2. Export without media; select the resulting .txt file below.
  3. Choose the quote for this same event and run change detection.
  4. Review extracted items alongside their source messages and price evidence.
