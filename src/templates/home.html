Recommended for this prototype

Upload a text export

  1. In WhatsApp, open the event's group chat.
  2. Choose More (or the chat menu) → Export chat → Without media.
  3. Select the exported .txt file and the quote for this same job.
  4. Choose Find changes. Review the extracted changes and linked chat evidence on the next page.

Only text exports are accepted. There is no quote upload: select the matching quote already in the list. Use synthetic chats only in this prototype; do not upload private client conversations.

Optional · requires a running bridge

Read a group directly

If the separate WhatsApp bridge is online and paired, you can choose a group and read its latest messages without exporting a file.

This prototype may show the bridge as offline. It does not mean WhatsApp is connected. If it is offline, use the text-export steps instead.
